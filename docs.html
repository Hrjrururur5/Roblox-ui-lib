A lightweight Roblox UI library that hooks into the native settings menu. Tabs, toggles, sliders, keybinds — all in a few lines of Lua.

Get Started View Example
Getting Started

Quick Start

Load the library with loadstring and start adding tabs.

lua 
local Lib = loadstring(game:HttpGet("YOUR_RAW_URL"))()

local main = Lib:AddTab("Main")

Lib:AddToggle(main, "God Mode", false, function(v)
    print("God Mode:", v)
end)
Note: Open the menu with the Roblox menu button, then click the Lib tab at the top.
Getting Started

Key System

Optionally lock your script behind a key. Call SetKeySystem before adding any tabs.

lua 
Lib:SetKeySystem({
    formula   = function(uid) return uid .. "-yourkey" end,
    portal    = "https://yoursite.netlify.app",  -- shown on key screen
    whitelist = "https://pastebin.com/raw/XXXXX", -- optional
})

If you skip SetKeySystem entirely, no key screen appears.

API

Methods

AddTab (name) → frame core

Creates a new tab in the menu. Returns the tab frame — pass it into all other methods.

lua
local main    = Lib:AddTab("Main")
local visuals = Lib:AddTab("Visuals")
AddSection (tab, text) core

Adds a section header label inside a tab to group related elements.

lua
Lib:AddSection(main, "PLAYER")
AddToggle (tab, label, default, callback, icon?) core

Adds an on/off toggle. Use AddToggleCfg to auto-save the value.

paramtypedescription
tabframeTab to add to
labelstringDisplay name
defaultboolStarting value
callbackfunction(v)Called when toggled
iconstring?Lucide icon name (optional)
lua
Lib:AddToggle(main, "Infinite Jump", false, function(v)
    -- v = true or false
end)

-- auto-saves value across sessions
Lib:AddToggleCfg(main, "God Mode", false, function(v) end)
AddSlider (tab, label, min, max, default, step, suffix, callback) core

Adds a draggable slider. Returns a setter function to update the value programmatically.

paramtypedescription
min / maxnumberValue range
defaultnumberStarting value
stepnumberSnap increment e.g. 1 or 0.1
suffixstringUnit label e.g. " st" or ""
callbackfunction(v)Called on change
lua
Lib:AddSlider(main, "Walk Speed", 8, 100, 16, 1, " st", function(v)
    game.Players.LocalPlayer.Character.Humanoid.WalkSpeed = v
end)
AddMultiplier (tab, label, values, default, callback) core

Segmented bar picker — lets the user pick from a fixed list of values. Great for presets.

lua
Lib:AddMultiplier(main, "FOV", {70, 90, 110, 130}, 90, function(v)
    game.Workspace.CurrentCamera.FieldOfView = v
end)
AddTextButton (tab, label, buttonText, callback, icon?) core

A row with a label on the left and a clickable button on the right.

lua
Lib:AddTextButton(main, "Respawn", "Go", function()
    game.Players.LocalPlayer:LoadCharacter()
end)
AddStatus (tab, label, initial, icon?) → updater core

Read-only display row. Returns an updater function fn(value, color?) to change it live.

lua
local setHP = Lib:AddStatus(main, "Health", "100")

-- update it later
setHP("50", Color3.fromRGB(255, 80, 80))
AddBind (tab, label, default, callback) core

Keybind row. User clicks the button then presses a key. Returns a getter function.

lua
Lib:AddBind(main, "Toggle ESP", Enum.KeyCode.X, function(key)
    print("Bound to", key.Name)
end)
AddDivider (tab) core

Adds a thin separator line between elements.

lua
Lib:AddDivider(main)
Notify (title, text, duration?) core

Sends a native Roblox notification popup.

lua
Lib:Notify("Loaded", "Script ready!", 4)
Guide

Config Persistence

The Cfg variants save values to deolib_config.json in the executor workspace and restore them automatically on next load.

lua
-- these remember their values across sessions
Lib:AddToggleCfg(main, "Auto Farm", false, function(v) end)
Lib:AddSliderCfg(main, "Speed", 8, 100, 16, 1, " st", function(v) end)
Lib:AddMultiplierCfg(main, "FOV", {70, 90, 110}, 90, function(v) end)
Guide

Full Example

lua
local Lib = loadstring(game:HttpGet("YOUR_RAW_URL"))()

-- optional key system
Lib:SetKeySystem({
    formula = function(uid) return uid .. "-abc123" end,
    portal  = "https://yourportal.netlify.app",
})

local main    = Lib:AddTab("Main")
local visuals = Lib:AddTab("Visuals")
local misc    = Lib:AddTab("Misc")

Lib:AddSection(main, "PLAYER")
Lib:AddToggleCfg(main, "God Mode", false, function(v) end)
Lib:AddSliderCfg(main, "Walk Speed", 8, 100, 16, 1, " st", function(v)
    game.Players.LocalPlayer.Character.Humanoid.WalkSpeed = v
end)

Lib:AddSection(main, "ACTIONS")
Lib:AddTextButton(main, "Respawn", "Go", function()
    game.Players.LocalPlayer:LoadCharacter()
end)

Lib:AddSection(visuals, "LIGHTING")
Lib:AddToggle(visuals, "Full Bright", false, function(v)
    local L = game:GetService("Lighting")
    L.Ambient = v and Color3.new(1,1,1) or Color3.new(0,0,0)
    L.GlobalShadows = not v
end)

local setFPS = Lib:AddStatus(visuals, "FPS", "—")
game:GetService("RunService").Heartbeat:Connect(function(dt)
    setFPS(math.floor(1 / dt))
end)

Lib:AddSection(misc, "BINDS")
Lib:AddBind(misc, "Toggle Menu", Enum.KeyCode.RightShift, function(key) end)

Lib:Notify("Loaded", "Script ready!", 3)
